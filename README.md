# Calculator (C++)

A simple console calculator made in C++ using a class (OOP). The user chooses an operation from a menu and enters two numbers.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Menu with 5 options (including exit)
- Message for a wrong menu choice

## Technologies Used
- C++
- Classes and objects (OOP)
- `switch` statement

## How to Run
1. Save the code as `calculator.cpp`.
2. Open a terminal in that folder.
3. Compile the code:
   ```
   g++ calculator.cpp -o calculator
   ```
4. Run the program:
   - Windows: `calculator.exe`
   - Linux / Mac: `./calculator`
